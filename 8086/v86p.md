# Victor V86P
8086-based Portable by Victor Technologies.

## Notes
- Not all versions of DOS 2 support hard disks. Using PC-DOS 2.0 or later is recommended.
- The BIOS is configurable by pressing Ctrl+Alt+Esc when prompted.
- RAM above 640k can be used as EMS or a RAMdisk.

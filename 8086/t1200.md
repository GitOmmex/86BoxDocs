# Toshiba T1200
8086-based successor to the T1100. Has a very unique 'Hard RAM' RAMdisk feature.

## Notes
- Not all versions of DOS 2 support hard disks. Using PC-DOS 2.0 or later is recommended.
- The BIOS is configurable by the user using a setup program in DOS.
- RAM above 640k can be used as EMS or a RAMdisk.

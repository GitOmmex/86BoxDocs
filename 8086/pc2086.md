# Amstrad PC2086
The Amstrad PC3086 was the successor to the [PC1640](pc1640.md). 

## Notes
- Configuring the BIOS requires an Amstrad system disk. A program called NVR.COM is needed.
- Uses a VGA card internally. Other video cards cannot be used.
- Unlike most 8086 systems, it supports double-density disks with the internal floppy controller.
- Comes with its own Amstrad mouse.

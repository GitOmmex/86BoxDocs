# Olivetti M21, M24, M24SP
8086-based IBM PC-clone by Olivetti. Also known as Persona 1600, AT&T PC 6300, and Xerox 6060.

## Notes
- BIOS is non-configurable.
- Has an internal enhanced CGA card (EGC 2413)
- May have issues booting using internal HDD adapter. Use IBM Fixed Disk Adapter instead.
- Will not boot if a 3.5" drive is set as B. Use 3.5" drive only in A, or only use 5.25" drives.

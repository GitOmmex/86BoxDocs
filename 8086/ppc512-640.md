# Amstrad PPC512/640
The Amstrad PPC512/640 were portable IBM PC compatibles by Amstrad.

## Notes
- Configuring the BIOS requires an Amstrad system disk. A program called NVR.COM is needed.
- Uses a CGA/MDA-compatible card internally. Outputs to an LCD display, but can output to monitors too. Other video cards can be used.
- Comes with its own Amstrad mouse.

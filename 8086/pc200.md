# Amstrad PC20(0)
The [Amstrad PC20(0)](https://en.wikipedia.org/wiki/Sinclair_PC200) was a Home Computer released in **1988**. Based off the [Amstrad PPC512](ppc512.md). Also known as Sinclair PC200.

## Notes
- Configuring the BIOS requires an Amstrad system disk. A program called NVR.COM is needed.
- Uses a CGA card internally. Other video cards can be used.
- Comes with its own Amstrad mouse.

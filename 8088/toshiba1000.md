# Toshiba T1000
One of the first DOS laptops. Has a very unique 'Hard RAM' RAMdisk feature. It has DOS 2.11 in ROM.

## Notes
- The BIOS is configurable by the user using the SETUP10 program on the BIOS ROM.
- The additional 640kB can be configured as a RAMdisk.

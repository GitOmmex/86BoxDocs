# Zenith Data Systems SupersPort (Z-184)
XT-class Laptop by Zenith Data Systems

## Notes
- BIOS is non-configurable.
- There is no visible memtest on boot.
- The display uses an internal controller. It is a CGA display.
- The machine will throw a Timer Interrupt Error if the CPU speed is above 4.77 MHz.
